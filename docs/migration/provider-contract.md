# Provider boundary and offline adapter

Eight network surfaces share native request/response/error/result types: ddg, github, github_code, jina, searxng, brave, openalex, meta. DDG normal fields are now native; the other seven remain pending. Feed remains the implemented local provider. A mutable transport receives an exact GET request URL plus canonical headers, returns raw HttpResponse, or a typed redacted failure. An offline adapter must match requests in order, return scripted synthetic responses/failures, reject unexpected calls, and assert all scripted steps were consumed. It never falls through to network. Provider implementations normalize responses to the existing SearchResult fields, preserve provider rank metadata, then use the existing rank pipeline. CLI query rewriting/candidate/category/highlight and slicing remain outside transport.

| Provider | Reference request / output / fallback boundary | Required offline adapter cases |
| --- | --- | --- |
| ddg | GET html.duckduckgo.com/html/?q, Accept text/html; result__a/result__snippet HTML fields; pre-rank limit slice | Ordinary/nested/Unicode/entity titles/snippets, redirect URLs, empty/no-snippet/dedup/retraction, signed limits, status/timeout/malformed HTML. No retry. |
| github | gh search repos with fixed JSON fields, 30 s; empty/nonzero/timeout falls back REST /search/repositories, stars sort, optional GITHUB_TOKEN | gh absence/success/fallback, REST request headers and nullable repo metadata, no response-body secret reflection. |
| github_code | GITHUB_TOKEN required; /search/code with text-match headers; requested max(0,limit), 100/page, at most 10 pages; invalid-query FetchError returns [] | Missing key/zero before request, repaired query/status detection, paging stops, fragments/path/repository metadata. |
| jina | Existing JINA_API_KEY posture and search endpoint; result normalization | Missing key/config, query encoding/headers, empty/results/errors; paid live execution prohibited in migration tests. |
| searxng | Existing KWR_SEARXNG_URL /search JSON; validated categories/engines/language/time_range/safesearch, up to bounded pages | Env defaults/validation before fetch, list shape/non-JSON WAF errors, page request order/dedup/empty, doctor preflight. No vendoring SearXNG code. |
| brave | Existing BRAVE_SEARCH_API_KEY; count/offset and country/language/freshness/safesearch validation | Missing key, invalid config before call, paging caps, web result/date metadata, redacted HTTP/JSON failures; paid live calls prohibited. |
| openalex | Existing API key/mailto/filter params; cursor pages, abstracts/location/PDF/license metadata; op:// resolution 10 s | Synthetic key/missing key, bounded op transcript errors without reading real vault, filters, at most 100/page cursor/empty/dedup caps, result metadata. |
| meta | Profile/provider query rewrite; up to four workers; component failures retained in metadata; fuse/rank and optional health ledger | Strict offline component adapters, deterministic clocks, selection/tie order/partial failures, metadata, health routing/prune/writer errors, no expanded live calls. |

HTTP safety changes and remaining charset/URL/proxy edges are inherited from PR #20 head 5da9fc8, now merged as main 96519c1 after parent's independent review and authorization. DNS/native trust initialization have no guaranteed full wallclock cancellation; authenticated proxy, unusual codecs, OS and live provider gates remain unverified. HTTP/2 and HTTP/3 are disabled in current reqwest features. If either is enabled later, explicitly disable and fixture-check protocol retries before preserving the zero-retry contract. Credentials remain in explicitly supplied environment/config at runtime; test adapters use public synthetic markers only. Provider errors never contain body previews or arbitrary subprocess diagnostics. Other seven providers remain unsupported until their native vertical behavior and matrix gates pass; the shared trait does not certify them.

Current native DDG evidence: 14 Python-derived parser cases and 84 search request/rank cases; strict adapter rejects unscripted/mismatched calls, remembers mismatches even if an error were caught, rejects unused steps, and preserves scripted error kinds without retries. 24 localhost CLI comparisons cover default/explicit provider, UTF-8 query encoding, categories/domain filters/candidate/signed limits, cached highlights, unchanged archive pages, empty/status/timeout behavior. No extra production fixture URL option or Python wrapper is introduced. The small streaming HTML parser covers normal fields and tested nested tags/entities/raw script/style; malformed/partial HTML, exotic attribute syntax and full transport edges still need reference cases before complete DDG parity.
